# Local Transcriber

Локальное веб-приложение для транскрибации аудио и видео на Apple Silicon. Медиафайлы
обрабатываются на компьютере через MLX Whisper и не отправляются в облачные сервисы.

## Возможности

- загрузка аудио и видео через локальную веб-страницу;
- drag-and-drop и отображение состояния обработки;
- три профиля качества Whisper;
- русский язык, английский или автоматическое определение;
- контекстная подсказка для имён и специальных терминов;
- экспорт в TXT, Markdown, JSON и SRT;
- последовательная очередь заданий в оперативной памяти;
- строгий офлайн-режим после предварительного скачивания модели;
- отображение скачанных моделей, живой статус обработки и отмена задания;
- отсутствие базы данных, аккаунтов и облачного API.

## Требования

- Mac с Apple Silicon;
- macOS 14 или новее;
- Python 3.11 или новее;
- FFmpeg и FFprobe;
- интернет только для установки зависимостей и первого скачивания модели.

## Быстрый запуск

```bash
brew install ffmpeg python@3.12
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
transcriber doctor
transcriber web
```

Откройте <http://127.0.0.1:8000>. При первом задании приложение скачает выбранную модель.
Исходный медиафайл при этом никуда не отправляется.

Модели сохраняются в папке `models/` внутри проекта. Она исключена из Git. Модели не
удаляются после закрытия приложения; удалить выбранную модель можно прямо в веб-интерфейсе.

Чтобы заранее скачать рекомендуемую модель и затем полностью запретить сетевые обращения:

```bash
transcriber models download balanced
transcriber web --offline
```

Альтернативный запуск без установки консольной команды:

```bash
PYTHONPATH=src python -m transcriber web
```

## Разработка и тесты

```bash
python -m pip install -e '.[dev]'
pytest
ruff check .
```

Подробности находятся в каталоге [`docs`](docs/README.md).

## Приватность

Сервер по умолчанию слушает только `127.0.0.1`. HTML, CSS и JavaScript входят в проект,
внешние CDN не используются. Загруженные файлы и результаты находятся во временном каталоге
и удаляются при штатной остановке приложения. История заданий не сохраняется.
