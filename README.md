# Local Transcriber

Локальное веб-приложение для транскрибации аудио и видео на macOS и Windows. На Mac
распознавание выполняется через MLX Whisper, на Windows — через Faster Whisper. Медиафайлы
не отправляются в облачные сервисы.

## Возможности

- загрузка аудио и видео через локальную веб-страницу;
- drag-and-drop и отображение состояния обработки;
- три профиля качества Whisper;
- автоматическая рекомендация модели по объёму памяти и доступному GPU;
- ориентировочные системные требования и предупреждения о тяжёлых режимах в интерфейсе;
- русский язык, английский или автоматическое определение;
- контекстная подсказка для имён и специальных терминов;
- экспорт в TXT, Markdown, JSON и SRT;
- последовательная очередь заданий в оперативной памяти;
- строгий офлайн-режим после предварительного скачивания модели;
- отображение скачанных моделей, живой статус обработки и отмена задания;
- отсутствие базы данных, аккаунтов и облачного API.

## Требования macOS

- Mac с Apple Silicon;
- macOS 14 или новее;
- Python 3.11 или новее;
- FFmpeg и FFprobe;
- интернет только для установки зависимостей и первого скачивания модели.

## Быстрый запуск на macOS

```bash
brew install ffmpeg python@3.12
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
transcriber doctor
transcriber web
```

Откройте <http://127.0.0.1:8000>. При первом задании приложение скачает выбранную модель.
Исходный медиафайл при этом никуда не отправляется.

## Быстрый запуск на Windows

Поддерживается 64-битная Windows 10/11. Откройте PowerShell в папке проекта и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup-windows.ps1
.\.venv\Scripts\transcriber.exe web
```

Сценарий создаст виртуальное окружение, установит Python-зависимости и при необходимости
установит FFmpeg через `winget`. Без NVIDIA приложение работает на CPU; при доступной и
настроенной CUDA-среде Faster Whisper автоматически использует GPU.

Модели сохраняются в папке `models/` внутри проекта. Она исключена из Git. Формат модели
выбирается автоматически для текущей ОС, поэтому скачанные на Mac MLX-веса не используются
Windows-движком и наоборот. Модели не удаляются после закрытия приложения; удалить выбранную
модель можно прямо в веб-интерфейсе.

Чтобы заранее скачать рекомендуемую модель и затем полностью запретить сетевые обращения:

```bash
transcriber models download balanced
transcriber web --offline
```

Альтернативный запуск без установки консольной команды:

```bash
PYTHONPATH=src python -m transcriber web
```

## Разработка и тесты

```bash
python -m pip install -e '.[dev]'
pytest
ruff check .
```

Подробности находятся в каталоге [`docs`](docs/README.md).

## Приватность

Сервер по умолчанию слушает только `127.0.0.1`. HTML, CSS и JavaScript входят в проект,
внешние CDN не используются. Загруженные файлы и результаты находятся во временном каталоге
и удаляются при штатной остановке приложения. История заданий не сохраняется.
