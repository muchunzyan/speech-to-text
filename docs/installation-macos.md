# Установка и запуск на macOS

Инструкция рассчитана на пользователя без опыта работы с Python.

## Что понадобится

- Mac с процессором Apple Silicon: M1, M2, M3, M4 или новее;
- macOS 14 или новее;
- подключение к интернету во время первой установки и первого скачивания модели;
- минимум 8 ГБ объединённой памяти;
- несколько гигабайт свободного места.

Intel Mac в текущей версии не поддерживается. Программа использует **Python 3.11** и устанавливает
его отдельно через Homebrew, не изменяя системный Python macOS.

## Шаг 1. Скачайте проект

1. Откройте [репозиторий проекта](https://github.com/muchunzyan/speech-to-text).
2. Нажмите **Code → Download ZIP**.
3. Дважды нажмите загруженный ZIP-файл, чтобы распаковать его.
4. Переместите папку `speech-to-text` в удобное место, например в `Документы`.

## Шаг 2. Установите Homebrew

Homebrew нужен, чтобы установить Python 3.11 и FFmpeg.

1. Откройте приложение **Терминал** через Spotlight.
2. Скопируйте и выполните официальную команду:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

3. Следуйте подсказкам установщика. macOS может запросить пароль пользователя. При вводе пароля
   символы не отображаются — это нормальное поведение Терминала.
4. Если установщик в конце покажет команды `Next steps`, обязательно скопируйте и выполните их.

Актуальная команда также опубликована на официальном сайте [brew.sh](https://brew.sh/).

## Шаг 3. Запустите программу

Откройте папку проекта и дважды нажмите **`start-macos.command`**.

Если macOS покажет сообщение **«could not be executed because you do not have appropriate access
privileges»**, это означает, что при распаковке ZIP-архива потерялось разрешение на запуск. Для
первого запуска:

1. Откройте **Терминал**.
2. Напечатайте `bash` и поставьте после него пробел — Enter пока не нажимайте.
3. Перетащите файл `start-macos.command` из Finder прямо в окно Терминала.
4. Нажмите Enter.

Получится команда примерно такого вида:

```bash
bash /Users/имя/Downloads/speech-to-text-main/start-macos.command
```

Скрипт сам восстановит необходимые права. Все следующие запуски можно выполнять обычным двойным
кликом по `start-macos.command`; повторять действия в Терминале не потребуется.

При первом запуске сценарий автоматически:

1. установит `python@3.11` и FFmpeg через Homebrew;
2. создаст изолированную папку `.venv`;
3. установит библиотеки программы;
4. проверит MLX и Metal;
5. запустит сервер и откроет <http://127.0.0.1:8000> в браузере.

Окно Терминала должно оставаться открытым всё время работы. Для остановки нажмите `Control+C` или
закройте окно. При следующих запусках снова дважды нажимайте `start-macos.command`.

## Если macOS блокирует файл по соображениям безопасности

Если вместо ошибки прав macOS сообщает, что не может проверить разработчика, нажмите файл правой
кнопкой мыши, выберите **Открыть** и подтвердите запуск. Делайте это только для проекта, скачанного
из официального репозитория.

## Ручная установка компонентов

Если автоматическая установка завершилась ошибкой, выполните в Терминале:

```bash
brew install python@3.11 ffmpeg
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
transcriber doctor
transcriber web
```

Формулы [`python@3.11`](https://formulae.brew.sh/formula/python%403.11) и
[`ffmpeg`](https://formulae.brew.sh/formula/ffmpeg.html) поддерживают Apple Silicon.

## Модели

При первом выборе модель скачивается в папку `models` внутри проекта. Аудио и видео остаются на
компьютере; интернет используется только для установки компонентов и загрузки весов моделей.

## Частые проблемы

### Сообщение о неправильной версии `.venv`

Удалите папку `.venv` и снова запустите `start-macos.command`. Папка `models` при этом останется на
месте, поэтому уже скачанные модели не потеряются.

### Homebrew установлен, но не найден

Выполните в Терминале:

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

После этого снова запустите `start-macos.command`.

### Браузер не открылся

Не закрывая окно Терминала, самостоятельно откройте <http://127.0.0.1:8000>.
