# Установка и запуск на Windows

Инструкция рассчитана на пользователя без опыта работы с Python и командной строкой.

## Что понадобится

- 64-битная Windows 10/11 на Intel/AMD либо Windows 11 ARM с поддержкой эмуляции x64;
- подключение к интернету во время первой установки и первого скачивания модели;
- минимум 8 ГБ оперативной памяти;
- несколько гигабайт свободного места для программы и моделей.

Программа использует **Python 3.11 (64-bit)**. Python 3.10 и более старые версии не подходят.
Для предсказуемой установки проект создаёт окружение именно на Python 3.11, даже если на
компьютере также установлена другая версия Python.

## Вариант 1 — автоматическая установка

### Шаг 1. Скачайте проект

1. Откройте [репозиторий проекта](https://github.com/muchunzyan/speech-to-text).
2. Нажмите **Code → Download ZIP**.
3. Откройте загруженный архив и выберите **Извлечь всё**.
4. Перейдите в извлечённую папку `speech-to-text`. Не запускайте программу прямо из ZIP-архива.

### Шаг 2. Запустите программу

Дважды нажмите файл **`start-windows.bat`** в корне проекта.

При первом запуске сценарий автоматически:

1. скачает официальный Python 3.11 x64 в локальную папку приложения и проверит его подпись;
2. установит FFmpeg через `winget`, если он отсутствует;
3. создаст изолированную папку `.venv`;
4. установит Python-библиотеки программы;
5. проверит окружение;
6. запустит локальный сервер и откроет <http://127.0.0.1:8000> в браузере.

Первая установка может занять несколько минут. Windows может показать запрос на подтверждение
установки компонентов. Окно `Local Transcriber` должно оставаться открытым всё время работы.
Чтобы остановить программу, закройте это окно или нажмите `Ctrl+C`.

При следующих запусках достаточно снова дважды нажать **`start-windows.bat`**.

## Вариант 2 — установить Python 3.11 вручную

Этот вариант нужен, если автоматическая загрузка Python заблокирована сетью или политиками Windows.

1. Скачайте официальный
   [Python 3.11.9 Windows installer (64-bit)](https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe).
2. Запустите установщик.
3. На первом экране обязательно отметьте **Add python.exe to PATH**.
4. Нажмите **Install Now** и дождитесь завершения.
5. Снова дважды нажмите `start-windows.bat`.

Не выбирайте 32-битный или ARM64-установщик. Даже на Windows ARM нужен именно x64-вариант:
CTranslate2 запускается через встроенную эмуляцию x64. Официальная страница выпуска:
[Python 3.11.9](https://www.python.org/downloads/release/python-3119/).

## Модели и видеокарта

Отдельная видеокарта не обязательна: программа может работать на процессоре. На компьютерах с
NVIDIA и настроенной CUDA-средой Faster Whisper автоматически использует GPU. Интерфейс показывает
рекомендованную для компьютера модель и предупреждает о слишком тяжёлых режимах.

При первом выборе модели она скачивается в папку `models` внутри проекта. Видео и аудио при этом
не отправляются в интернет — загружаются только веса модели.

## Частые проблемы

### Ошибка `No matching distribution found for ctranslate2`

Она означает, что `.venv` создан на Python ARM64. Готовые Windows-пакеты CTranslate2 выпускаются
для x86-64. Актуальный установщик автоматически скачивает отдельный Python x64 и пересоздаёт
несовместимую `.venv`. Скачайте свежую версию проекта и снова запустите `start-windows.bat`.

Проверить архитектуру существующего окружения можно командой:

```powershell
.\.venv\Scripts\python.exe -c "import platform; print(platform.machine())"
```

Правильный результат — `AMD64`, в том числе на Windows ARM под эмуляцией.

### Ошибка доступа при запуске из `\\Mac\Home` или другой общей папки

Не запускайте проект из общей папки Parallels, сетевого диска или прямо из ZIP-архива. Скопируйте
всю папку проекта на локальный диск Windows, например в `C:\LocalTranscriber`, после чего снова
откройте `start-windows.bat`. Установщик теперь распознаёт UNC-путь и показывает понятную ошибку.

### Ошибка `ParserError: TerminatorExpectedAtEndOfString`

PowerShell 5.1 иногда неправильно распознаёт кириллицу в UTF-8 без BOM. В актуальной версии проекта
файлы `setup-windows.ps1` и `start-windows.ps1` уже сохранены как **UTF-8 with BOM**, поэтому ошибка
не должна возникать.

Если используется старая копия проекта, файл можно исправить в PowerShell:

```powershell
$path = (Resolve-Path .\scripts\setup-windows.ps1).Path
$content = [System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)
$encoding = New-Object System.Text.UTF8Encoding($true)
[System.IO.File]::WriteAllText($path, $content, $encoding)
```

Проще и надёжнее заново скачать актуальную версию проекта с GitHub.

### Сообщение о неправильной версии `.venv`

Удалите папку `.venv` из каталога проекта и снова запустите `start-windows.bat`. Модели находятся
в отдельной папке `models` и при этом не удаляются.

### FFmpeg установлен, но не найден

Перезагрузите Windows и снова откройте `start-windows.bat`. Если это не помогло, установите FFmpeg
командой в PowerShell:

```powershell
winget install --id Gyan.FFmpeg --exact
```

### Браузер не открылся

Не закрывая окно программы, самостоятельно откройте <http://127.0.0.1:8000>.

### Windows SmartScreen блокирует файл

Убедитесь, что проект скачан из официального репозитория. Затем нажмите **Подробнее → Выполнить в
любом случае** либо откройте свойства файла и отметьте **Разблокировать**, если такой пункт есть.
